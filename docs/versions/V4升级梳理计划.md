## 一、版本号规则声明

从 V4.0 起，本项目采用语义化版本规则：

| 版本格式 | 含义 | 示例 |
|---------|------|------|
| **V大版本** | 重大功能架构更新、突破性变更 | V1 → V2 → V3 → V4 |
| **v4.x** | 小版本更新、功能增强、Bug 修复 | v4.1, v4.2, v4.3… |

每次更新必须走"版本闸门"流程：
1. 更新 `CHANGELOG.md`
2. 留存方案快照到 `docs/versions/`
3. 留存可回滚代码快照到 `releases/`
4. 更新 `config.py` 中的 `PLATFORM_VERSION` 常量

## 二、变更清单

### 2.1 学情分析全面重构（核心亮点）

| 变更 | 改造前（V3） | 改造后（V4） |
|------|------------|------------|
| 数据来源 | 手动粘贴 JSON | 自动从数据库取当前课程成绩 |
| 展示形式 | 纯文本 | ECharts 5.5 图表 + AI 文字解读 |
| 交互方式 | 点击按钮看结果 | 自动加载 + 图表交互 |
| 视觉效果 | 无 | 专业配色 + 渐变色系 |

**新增可视化组件**：

| 组件 | 类型 | 数据源 |
|------|------|--------|
| KPI 指标卡 | 统计卡片 | `/api/teacher/dashboard` |
| 班级能力雷达 | ECharts 雷达图 | `/api/teacher/radar` |
| 章节掌握度 | ECharts 水平柱状图 | `/api/teacher/gantt` |
| 综合分分布 | ECharts 甜甜圈图 | `/api/analytics/db-grades` |
| 学习活跃度 | ECharts 散点图 | `/api/analytics/db-grades` |
| 学生排名表 | 表格 + 进度条 | `/api/teacher/rankings` |

**新增后端 API**：

| 接口 | 功能 |
|------|------|
| `GET /api/analytics/db-grades` | 获取当前课程所有成绩 |
| `POST /api/analytics/trend` + `use_db: true` | 一键 AI 趋势分析 |
| `POST /api/analytics/risk` + `use_db: true` | 一键 AI 风险预警 |
| `POST /api/analytics/mastery` + `use_db: true` | 一键 AI 掌握度分析 |
| `POST /api/analytics/full-report` + `use_db: true` | 一键 AI 完整报告 |

**涉及文件**：
- `templates/teacher/analytics.html` — 完全重写
- `app.py` — 新增 `api_analytics_db_grades` 路由
- `database.py` — `get_grades()` 加 `course_id` 过滤；`save_grade()` 加 `course_id` 参数
