# V4.2 升级计划：性能优化

> 文档版本：V4.2 | 日期：2026-07-23 | 负责人：朱景峰
> 基线快照：`releases/v4.1/`

## 变更清单

### 1. 数据库索引
- `idx_grades_course`：grades(course_id, student_id)
- `idx_attempts_course`：student_attempts(course_id, chapter_id)
- `idx_prompt_cache_lookup`：prompt_cache(course_id, chapter_id, func_type)
- `idx_course_docs_course`：course_documents(course_id)
- `idx_questions_course`：questions(course_id)

### 2. 合并首页 API
- 新增 `GET /api/teacher/home`：一次返回 dashboard + grades + stats
- 首页从 3 次请求减为 1 次

### 3. 前端缓存
- localStorage 缓存首页数据，30 秒 TTL
- 30 秒自动轮询刷新

## 涉及文件
- `src/app.py`：新增 `api_teacher_home` 路由
- `src/config.py`：`PLATFORM_VERSION = "4.2"`
- `CHANGELOG.md`：新增 [4.2] 条目
- `templates/teacher/dashboard.html`：loadDashboard 重构为合并 API + 缓存
