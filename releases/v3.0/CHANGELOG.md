# 版本变更日志 (CHANGELOG)

> **版本规则**：主版本.次版本 (X.Y)。每一次更新都必须走"版本闸门"流程：
> ① 更新本文件 ② 在 `docs/versions/` 留存方案快照 ③ 在 `releases/` 留存可回滚代码快照 ④（可选）`git tag vX.Y`
> 回滚方式：用 `releases/vX.Y/` 覆盖当前源码即可回到该版本。

## [3.0] - 2026-07-22（✅ 已实施完成）
**主题：课程无关化 + 教师端开放4大智能体 + 双端首页功能区重构**

- **课程成为顶层租户**：所有功能（RAG / 出题 / 数字人 / 图谱 / 雷达 / 排名 / 甘特）按 `course_id` 隔离，平台从"Python专用"升级为"任意课程通用"。
- **课程体系数据化**：章节与模块（雷达维度）从 `knowledge_base.py` 硬编码改为数据库 `course_chapters` 存储；新课件（含大纲/文档）上传即生效，无需改代码。
- **知识库按课程隔离**：每门课程独立知识库，支持上传 PDF / DOCX / TXT 切片建库；RAG 检索仅命中当前课程文档。
- **教师端开放4大 AI 智能体**：RAG 智能答疑、智能出题与判分、数字人讲解生成、知识图谱——与学生端共用同一套 Agent 能力，按角色呈现不同 UI。
- **双端首页重构为"功能区"**：师生进入首页均为功能卡片导航（功能模块入口），而非纯指标看板。
- **雷达维度动态化**：雷达按课程的"模块(module)"动态聚合，甘特按课程章节动态生成，彻底去除 `ABILITY_DIMENSIONS` 硬编码。

### 数据库变更
- 新增 `course_chapters`（课程章节/模块，含 keywords/objectives/key_points 等富文本 JSON）
- 新增 `course_documents`（按课程的知识库切片）
- 改造 `questions` / `student_attempts` / `wrong_books` / `mastery_timeline`：补充 `course_id`
- Python 12 章作为"示例课程"种子数据写入 `course_chapters`

### 验证结果（2026-07-22 回归测试 14/14 通过）
- 双课程并行：示例(Python, 12章) + 高数(4章) 互不串扰
- RAG 检索按 `course_id` 隔离：高数提问仅命中高数文档，不串 Python
- 雷达维度由课程 `module` 驱动：高数=["基础概念","微积分","线性代数"]，Python=["基础语法"…"面向对象"]5维
- 排名 / 甘特均按课程作用域过滤
- HTTP：`/api/version` 返回 3.0；教师登录 + 当前课程章节加载正常
