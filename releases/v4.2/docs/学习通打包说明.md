## 二、文件要求

| 项目 | 要求 |
|------|------|
| **演示视频** | 5分钟以内，H.264编码，MP4格式，≤100MB |
| **设计报告** | PDF格式，图文并茂，含系统截图 |
| **截图** | PNG或JPG，每张≤2MB，清晰展示功能界面 |
| **命名规范** | 数字序号+中文描述，方便评委按顺序查看 |

## 三、上传流程

1. 打开学习通（https://53ek4ndq.mh.chaoxing.com/）
2. 登录超星账号（扫码或手机号）
3. 找到「四川省第二届教师人工智能应用能力大赛」入口
4. 选择赛道三，填写报名信息
5. 上传作品包（整个文件夹打包为ZIP）
6. 确认赛道三、职业教育组、宜宾工业职业技术学院信息
7. 提交后下载存证

## 四、注意事项

- ❗ 版本号一致性：报告、演示视频、运行系统版本统一为 **V4.0**
- ❗ 赛道选择：务必选「赛道三：AI助力课外全场景减负增效」
- ❗ 分组选择：职业教育组（高职）
- ❗ 文件大小：学习通上传大小限制请提前确认（通常200MB以内）
- ❗ 备份：提交后建议本地保留完整作品包以备省赛使用
