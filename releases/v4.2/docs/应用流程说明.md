## 场景一：教师单元备课全流程

### 流程概述

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 上传课件   │ → │ AI 生成   │ → │ 配套出题  │ → │ 学情预案  │
│ 选择章节  │    │ 完整教案  │    │ 练习题   │    │ 数据准备  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
    │               │               │               │
    ▼               ▼               ▼               ▼
  人工环节      AI 替代环节      AI 替代环节      AI 替代环节
  耗时约 2h     原 2h → 10min   原 1h → 3min    原 30min → 1min
```

### 详细步骤

| 步骤 | 操作 | 环节 | 工具/页面 |
|:----:|------|:----:|----------|
| 1 | 教师选择课程章节，查看预设知识体系 | 人工 | 备课页面章节选择 |
| 2 | 选择教案生成功能，填写额外要求（可选） | 人工 | 备课页面功能选择 |
| 3 | **系统调用 DeepSeek API，根据章节知识库生成结构化教案** | **AI 替代** | 后端 `lesson_prep.py` |
| 4 | 教师预览教案，可调整或重新生成 | 人工 | 备课页面结果展示区 |
| 5 | **配套练习题自动生成** | **AI 替代** | 出题页面一键生成 |
| 6 | 教案存档，备课完成 | 人工 | 系统自动记录 |

### 减负效果

- 教案生成：2小时 → 10分钟，效率提升 **12 倍**
- 课件大纲：1小时 → 5分钟，效率提升 **12 倍**
- 思政融入方案：30分钟 → 1分钟，效率提升 **30 倍**

## 场景二：作业批改与教学反馈全流程

### 流程概述

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 学生提交  │ → │ AI 批量   │ → │ 错题自动  │ → │ 学情数据  │
│ 代码作业  │    │ 批改评分  │    │ 归集分析  │    │ 自动更新  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
    │               │               │               │
    ▼               ▼               ▼               ▼
  学生环节       AI 替代环节      AI 替代环节      AI 替代环节
  在线提交      原 3h→10min     原 1h→实时      原 半天→1min
```

### 详细步骤

| 步骤 | 操作 | 环节 | 技术说明 |
|:----:|------|:----:|---------|
| 1 | 学生在线提交代码作业（.py 文件或粘贴代码） | 学生操作 | 学生端提交页面 |
| 2 | **系统自动评分：正确性(40%)+规范(20%)+效率(20%)+创新(20%)** | **AI 替代** | `code_grader.py` + DeepSeek |
| 3 | **Bug 诊断：定位错误行，解释原因，给出修复建议** | **AI 替代** | `diagnose_bug()` |
| 4 | **错题自动归集至学生错题本，写入 `wrong_books`** | **AI 替代** | 数据库自动写入 |
| 5 | **学情数据更新：正确率、掌握度雷达图实时刷新** | **AI 替代** | `data_sync.py` |
| 6 | 教师查看批改结果，可追加评语 | 人工 | 批改页面 |

### 减负效果

- 代码批改（50人班）：3小时 → 10分钟，效率提升 **18 倍**
- Bug 诊断（每题）：5分钟 → 10秒，效率提升 **30 倍**
- 学情数据整理：半天 → 1分钟，效率提升 **240 倍**

## 场景三：顶岗实习家校沟通全流程

### 流程概述

```
┌──────────┐    ┌──────────┐    ┌──────────┐    ┌──────────┐
│ 导入实习  │ → │ 选择场景  │ → │ AI 批量   │ → │ 教师审核  │
│ 学生名单  │    │ 模板    │    │ 生成文案  │    │ 一键发送  │
└──────────┘    └──────────┘    └──────────┘    └──────────┘
    │               │               │               │
    ▼               ▼               ▼               ▼
  人工环节      人工环节         AI 替代环节      人工环节
  1次导入       选择即可        原 30min→2min    1min完成
```

### 详细步骤

| 步骤 | 操作 | 环节 | 说明 |
|:----:|------|:----:|------|
| 1 | 教师导入/查看实习学生名单 | 人工 | 实习沟通页面预置学生数据 |
| 2 | 选择沟通场景：日常反馈 / 预警通知 / 实习鉴定 | 人工 | 三种场景模板可选 |
| 3 | 填写补充信息（本周表现、异常情况等） | 人工 | 选填 |
| 4 | **AI 根据场景模板 + 学生信息生成个性化沟通文案** | **AI 替代** | `internship.py` + DeepSeek |
| 5 | 教师预览文案，可调整或重新生成 | 人工 | 实时编辑 |
| 6 | 一键复制发送给家长（微信/短信/学习通） | 人工 | 系统外操作 |

### 减负效果

- 单生沟通文案：30分钟 → 2分钟，效率提升 **15 倍**
- 班级批量生成：原本逐个写的 2小时 → 5分钟
